# 경매 입찰·대출 자금 계산기 v1.20.7

## v1.20.7
- 저장목록 표에서 **상태를 바로 선택**할 수 있습니다: 미검토 / 고민중 / 입찰 O / 입찰 X / 입찰완료.
- **별** 열을 복구했습니다. ☆/★ 종류를 표에서 바로 선택하고 Firebase에 저장합니다.
- **지역폴더** 열을 복구했습니다. 기존 폴더 선택 또는 `＋ 새 폴더 추가…`로 바로 지정할 수 있습니다.
- 별/지역폴더도 다른 열처럼 **엑셀형 필터·정렬**이 가능하고, 열 제목을 마우스로 끌어 순서를 바꿀 수 있습니다. 이전 버전 열순서를 쓰는 기기에서는 별은 상태 뒤, 지역폴더는 소재지 뒤에 자동 삽입됩니다.
- 피드백 달력의 `꼭 들어갈 물건` 복수선택 팝업이 화면 밖으로 밀리거나 목록을 과도하게 덮지 않도록 위치·폭·높이를 수정했습니다. 모바일에서는 화면 중앙형 팝업으로 표시됩니다.
- 공공데이터 설정에서 **법정동코드 + 건축HUB + 아파트 실거래 3개 API를 한 번에 연결 확인**합니다. 서비스키 인증/권한 오류도 더 명확히 표시합니다.
- 공공데이터 서비스키는 계속 **브라우저 localStorage에만 저장**하고 Firebase/백업에는 포함하지 않습니다.
- 기존 v1.20.6의 실거래 건별 조사메모, 호가 건별 입력, 부동산 조사, 15항목 피드백 자동완성, 입찰결과 달력 누적기록, 검색/날짜검색, 열 드래그, 모바일 개선 기능을 유지합니다.

## 공공데이터 사용 순서
1. `공공데이터 키 설정` → 공공데이터포털 일반 인증키 입력 → `키 저장`.
2. `3개 API 연결 확인`으로 법정동코드 / 건축HUB / 아파트 실거래 응답을 확인.
3. 저장목록에서 물건 체크 → `선택 공공자료 조회`, 또는 `전체 공공자료 조회`.
4. 상세 `시세입력`의 실거래 목록에서 거래 건별 조사메모를 입력.

## v1.20.6
- `시세입력`을 예상매도가 입력 메뉴와 분리했습니다. 이제 이 메뉴에는 **공공 실거래 + 거래별 조사메모**, **호가 건별 입력(금액·동·층·조건)**, **부동산 통화 건별 기록**만 저장합니다.
- 실거래 자동조회 결과 옆에 수리·뷰·특수관계인 거래 여부 등을 직접 메모할 수 있습니다.
- `피드백요청` 메뉴명을 **피드백**으로 변경했습니다. 사용자가 제공한 15개 항목 요청양식을 구조화했고, 사건번호·매각기일·주소·가용투자금·부동산 통화기록 등은 자동으로 요청문에 조합됩니다.
- 기존 `이 물건 요청 추가메모` 대신 **피드백 답변**을 별도 저장합니다.
- 피드백 달력은 입찰결과 저장 후에도 해당 물건을 제거하지 않고 **패찰/낙찰/취소 결과와 실제 낙찰가·내 입찰가·응찰자 수**를 함께 남깁니다. 상단에는 누적 입찰기록 건수도 표시합니다.

## v1.20.5 기반 유지 기능
- 저장목록의 `선택` 열을 제외한 모든 열을 마우스로 끌어 순서를 바꿀 수 있으며 순서를 기기에 저장합니다.
- 검색창 옆에 매각기일 달력을 복구했습니다. 하루 검색과 시작일~종료일 기간 검색을 지원합니다.
- 검색/날짜 조건과 엑셀형 열 필터를 동시에 적용할 수 있습니다.
- 모바일 상세 화면 폭/높이와 실제입찰 화면을 재배치했습니다. 1·2·3차 입찰가 입력은 세로 카드로 모두 보이고, 결과표는 1·2·3차 열을 한 화면에 표시합니다.


## 이번 버전 핵심
- 저장목록의 `넓게 보기/기본 너비` 버튼을 제거했습니다.
- 상세의 `상세계산/대출/비용/실제입찰/입찰결과/시세입력/피드백요청/메모` 탭을 눌러도 브라우저 화면이 상단으로 이동하지 않도록 현재 스크롤 위치를 유지합니다.
- 저장목록을 엑셀형 표로 사용: 각 열의 ▼ 버튼에서 오름차순/내림차순 정렬, 값 검색, 복수 체크 필터.
- 화면 위쪽의 기존 상태/등급/별/간이필터는 숨기고 표 헤더 필터로 통일.
- 옥션원 원문 재분석, 공공자료 조회, 기존자료 후보 확인 기능 유지.
- 표의 물건을 펼쳐 실제입찰/대출/비용/시세/피드백요청 등 기존 상세 기능 사용.
- 상세영역과 목록 사이 높이는 드래그로 조절하고 마지막 높이를 기억.
- 2~4건 선택 비교 기능 유지.
- `피드백 일정짜기` 모드: 고민중·입찰 O 물건을 목록에서 직접 선택. 동시 진행 최대 2건 규칙에 따라 함께 선택할 수 없는 경매일 물건은 즉시 비활성화되며, 선택을 해제하면 다시 활성화.
- 선택한 일정은 각 경매일의 기본 피드백일(4영업일 전, 주말/공휴일 제외)로 저장 가능. 기존 요청 진행중 물건은 슬롯에 자동 반영.
- `피드백 달력`을 누르면 계산기/저장목록을 숨기고 달력이 화면 최상단에 표시. 경우의 수 계산 기능도 유지.

## 사용 흐름
1. 옥션원 검색결과 복사 → 붙여넣기/저장
2. 원문 재분석 / 공공자료 조회
3. 표 헤더 필터로 1·2층, 대항력, 유찰횟수, 최저가율, 매각기일 등을 정렬·필터
4. 남은 물건부터 시세입력 → 가능입찰가율 확인 → 상태변경
5. 필요하면 2~4건 비교
6. `피드백 일정짜기`에서 경매일 조합을 선택하고 충돌을 확인한 뒤 일정 저장
7. `피드백 달력`에서 요청/결과를 관리

기존 Firebase 동기화와 백업 구조를 유지합니다.

## v1.20.6 추가 피드백 일정 표시
- 저장목록의 `피드백 일정짜기`에서 현재 선택과 겹쳐 바로 선택할 수 없는 물건은 자동 잠금됩니다.
- 기본 요청일(매각 4영업일 전)보다 **1영업일 늦게 요청하면 가능한 물건**은 완전 불가와 구분해 빨간색으로 표시합니다. 체크는 잠긴 상태를 유지하고, 가능한 늦은 요청일을 함께 보여줍니다.
- `피드백 경우의 수`의 포기/후순위 목록에서도 +1영업일 늦추면 가능한 물건을 빨간색으로 표시합니다.


## v1.20.6
- 피드백 달력의 `피드백 경우의 수` 영역을 접기/펴기 가능하게 변경하고 상태를 브라우저에 기억합니다.
- `꼭 들어갈 물건`을 체크박스형 복수선택으로 변경했습니다. 여러 건을 필수로 고정한 상태에서 가능한 조합을 다시 계산하며, 필수 물건끼리 동시 2건 제한을 넘으면 충돌 안내를 표시합니다.
