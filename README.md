## v1.17.0
- 옥션원 검색결과 텍스트 전체 복사/붙여넣기 일괄가져오기 정밀화
- 주소 지번(예: 35-24)을 사건번호로 오인하던 파서 오류 수정
- 사건번호·주소·단지·동/층/호·전용/공급·대지권·감정가·최저가·유찰횟수·현재가율·평당가·매각기일/시간·조회수·공시가격구간·특수표시 저장
- 새로 가져온 물건에 동일번지/인근 낙찰가율 78% 같은 임의값을 넣지 않음
- 옥션원 미검토 물건별 자료완성도와 남은 조사칸 표시
- 기존 저장자료에서 단지/동/평형/라인이 맞는 객관값만 자동 재사용 및 저장
- 미검토 전체 기존자료 자동보완 버튼 추가
- 기존 v1.16.3에서 잘못 들어간 2035타경24(영진크로바) 저장건 자동 복구
- 낙찰가율 1~130% 범위 지원
- 공공데이터 실거래/K-apt/건축HUB 연결 대상과 수동확인 항목을 화면에서 구분

### 공공데이터 자동화 안내
국토교통부 실거래 API와 K-apt/건축HUB는 무료이지만 공공데이터포털 서비스키가 필요합니다. 이 ZIP에는 키를 하드코딩하지 않습니다. 현재 버전은 옥션원 복사문구와 기존 Firebase 저장자료만으로 가능한 자동화를 즉시 사용합니다.
