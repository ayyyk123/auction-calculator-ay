# 경매 입찰·대출 자금 계산기 v1.11.6

## 변경사항
- 피드백 달력 추가: 고민중·입찰 O 물건만 달력에 자동 반영
- 경매기일에서 4영업일을 역산한 피드백 기준일 자동 계산(토·일·대한민국 공휴일·대체공휴일 제외)
- 사건번호 클릭 시 피드백 요청 여부·실제 요청일·입찰결과·계획일 입력
- 사건번호 드래그로 피드백 요청 계획일 변경, 기준일은 사건번호 옆에 계속 표시
- 하루 물건이 많으면 +N건 버튼으로 펼쳐보기
- 달력 아래에서 입찰안함 물건 별도 필터·검색
- 피드백 화면에서 해당 사건의 계산기·실제입찰 화면으로 바로 이동
- 기존 Firebase revision 충돌방지와 저장 데이터 구조 유지
- 물건 기본정보에 현관 구조(계단식·복도식·혼합식) 추가
- 기타 특이사항 한 줄 입력란 추가
- 사용승인년도는 저장목록에서 `2016년식`처럼 표시
- 저장 폴더 이름 수정 기능 추가
- 폴더 이름 수정 시 해당 폴더의 기존 저장자료도 함께 새 폴더명으로 안전하게 변경
- 지역별 폴더 보기는 가로 버튼 대신 `폴더 목록` 버튼을 눌러 선택하는 방식으로 변경
- 저장 시 `입찰하기 / 입찰 안 함` 선택과 선택 사유 입력 추가
- 저장카드에 입찰 결정과 사유 표시
- `입찰하기`로 저장한 물건에만 작은 실제입찰 버튼 표시
- 입찰 안 함으로 바꾸면 기존 실제입찰 자료 삭제 여부 확인
- 기존 Firebase 동기화·revision 충돌방지·삭제 tombstone 유지
