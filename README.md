# 경매 입찰·대출 자금 계산기 v1.9.2

## v1.9.2 긴급 수정
- 메인 제목 옆에 `v1.9.2` 버전 배지 표시
- `✎ 이메일 수정` 버튼을 로그인 이메일 바로 옆에 고정
- CSS로 표시 상태를 강제해 화면 너비와 관계없이 보이도록 수정

## v1.9.1 긴급 수정
- `로그인 이메일 수정` 버튼을 `최신자료 저장` 옆에 항상 표시
- 로그인 전에는 비활성화, 로그인 후 즉시 사용 가능
- 기존 UID와 Firestore 저장자료 유지 방식은 동일

## 주요 변경
- 실제입찰 화면의 기본값을 자동계산으로 변경
- 취등록세: 일반주택·중과 미적용 기준으로 입찰가와 전용면적에 따라 자동계산
- 법무비: 업로드한 엑셀의 낙찰가 구간표 자동 적용
- 중개보수: 서울시 주택 매매 상한요율과 한도액 자동 적용
- 종합소득세: 누진세율 자동 적용
- 네 항목 모두 `자동 / 직접` 전환 가능
- 로그인 상태에서 `이메일 수정` 가능
- 이메일 변경 시 UID와 Firestore 저장자료 유지
- 기존 지역폴더·정렬·실제입찰·충돌방지·최신자료 저장 기능 유지

## 이메일 오타 수정
1. 현재 오타 이메일 계정으로 로그인된 상태를 유지합니다.
2. Firebase Authentication 사용자 목록에 올바른 Gmail 계정이 이미 있으면, 그 올바른 Gmail 행만 삭제합니다.
3. 오타 이메일 계정은 삭제하지 않습니다.
4. 웹페이지의 `이메일 수정`에서 새 이메일과 현재 비밀번호를 입력합니다.
5. 새 이메일로 온 확인 링크를 누릅니다.
6. 같은 비밀번호로 새 이메일에 로그인합니다.

## 취등록세 자동계산 전제
일반주택 기본세율을 사용하며 다주택 중과·법인·특수 감면은 반영하지 않습니다.
전용면적 85㎡ 초과인 경우 농어촌특별세 0.2%를 더합니다.
중과 대상이면 `직접`으로 바꾸고 실제 세율을 입력하세요.
