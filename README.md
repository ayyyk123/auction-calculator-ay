# 경매 입찰·대출 자금 계산기 v1.11.0

## 변경사항
- 상단에 `피드백 달력` 버튼 추가
- 저장목록의 사건번호·물건명·경매기일을 피드백 달력에서 자동 불러오기
- 피드백 요청 체크, 실제 요청일, 진행 중·패찰·낙찰·입찰취소 상태 관리
- 동시에 진행 중인 피드백 요청을 최대 2건으로 자동 제한
- 빈자리가 생기는 예상일과 그날 요청 가능한 **가장 빠른 입찰일** 자동 계산
- 입찰기일 4영업일 전 피드백 요청 마감일 자동 표시
- 토요일·일요일, 법정공휴일, 음력 설·추석·부처님오신날 및 대체공휴일 자동 제외
- 2026년부터 노동절·제헌절 공휴일 규정 반영
- 임시공휴일·선거일을 직접 추가·삭제 가능
- 피드백 일정과 추가 휴일을 Firebase로 PC·핸드폰 자동 동기화
- JSON 백업에 피드백 달력 자료 포함
- 기존 계산·저장목록·지역 폴더·동기화 충돌방지 기능 유지
