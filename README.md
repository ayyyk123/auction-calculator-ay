# 경매 입찰·대출 자금 계산기 v1.11.9

## 변경사항
- 피드백 달력 추가: 고민중·입찰 O 물건만 달력에 자동 반영
- 경매기일에서 4영업일을 역산한 피드백 기준일 자동 계산(토·일·대한민국 공휴일·대체공휴일 제외)
- 사건번호 클릭 시 피드백 요청 여부·실제 요청일·입찰결과·계획일 입력
- 사건번호 드래그로 피드백 요청 계획일 변경, 기준일은 사건번호 옆에 계속 표시
- 하루 물건이 많으면 +N건 버튼으로 펼쳐보기
- 달력 아래에서 입찰안함 물건 별도 필터·검색
- 피드백 화면에서 해당 사건의 계산기·실제입찰 화면으로 바로 이동
- 기존 Firebase revision 충돌방지와 저장 데이터 구조 유지
- 물건 기본정보에 현관 구조(계단식·복도식·혼합식) 추가
- 기타 특이사항 한 줄 입력란 추가
- 사용승인년도는 저장목록에서 `2016년식`처럼 표시
- 저장 폴더 이름 수정 기능 추가
- 폴더 이름 수정 시 해당 폴더의 기존 저장자료도 함께 새 폴더명으로 안전하게 변경
- 지역별 폴더 보기는 가로 버튼 대신 `폴더 목록` 버튼을 눌러 선택하는 방식으로 변경
- 저장 시 `입찰하기 / 입찰 안 함` 선택과 선택 사유 입력 추가
- 저장카드에 입찰 결정과 사유 표시
- `입찰하기`로 저장한 물건에만 작은 실제입찰 버튼 표시
- 입찰 안 함으로 바꾸면 기존 실제입찰 자료 삭제 여부 확인
- 기존 Firebase 동기화·revision 충돌방지·삭제 tombstone 유지

## v1.11.6
- 동일번지·인근 낙찰가율을 이상치 완화, 동일번지 우선, 최근 연도 가중으로 보정해 낮음·대표·높음 3개 예상가율 자동 산출
- 낮음·대표·높음 각각의 최소 자기자본 자동 계산
- 대표 예상가율은 예산 초과지만 낮음 예상가율에서는 가능한 고민중 물건을 저장목록에서 `↘ 낮음 기준 예산OK`로 강조
- 저장목록에 낮음/대표/높음 예상가율을 함께 표시


## v1.11.7
- 저장목록의 `최소자본` 금액이 어떤 입찰가율을 기준으로 계산됐는지 함께 표시
- 낮음 예상가율과 일치하면 `낮음 기준`, 대표 예상가율이면 `대표 기준`, 높음 예상가율이면 `높음 기준` 배지 표시
- 세 시나리오와 다른 수동 입찰가율로 저장한 경우 `직접설정 00.0%`로 표시
- 기존 `↘ 낮음 기준 예산OK` 후보 강조와 낮음/대표/높음 예상범위 표시는 그대로 유지

## v1.11.8
- 저장목록 사건번호/제목 앞에 계산기·피드백 달력과 동일한 관심 별표를 색상까지 그대로 표시
- 저장목록의 최소자본 표시를 `대표 최소 4,350만원 (예산 4,400만원)`처럼 한 줄로 통합
- 낮음/대표/높음 시나리오와 일치하면 각각 `낮음`, `대표`, `높음`을 앞에 표시하고, 수동 입찰가율이면 `직접 00.0%`로 표시
- 기존 `↘ 낮음 기준 예산OK` 강조와 낮음/대표/높음 예상범위는 그대로 유지


## v1.11.9
- 예상가율 산식을 단순화: 동일번지 평균과 인근 평균에 사용자가 정한 반영비중만 적용하고, 연도 가중·개별 이상치 가중·가중 분위수 계산은 제거
- 낮음·높음 예상가율은 전체 입력사례의 퍼짐(표준편차)을 이용해 대표값 아래·위의 현실적인 범위로 계산하며, `낮음 ≤ 대표 ≤ 높음`을 항상 유지
- 낙찰연도는 기존 데이터 호환을 위해 유지하되 계산에는 쓰지 않고 참고용으로만 저장
- 낮음/대표/높음 예상가율 카드를 누르면 `적용할 입찰가율` 조절바가 해당 값으로 즉시 이동하고, 계산결과도 같은 값으로 즉시 재계산
- 선택한 시나리오 카드는 테두리로 강조되며 수동으로 조절바를 움직이면 현재 값과 일치하는 카드만 자동 강조
