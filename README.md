# v1.16.2 옥션원 PDF 고정밀 OCR

- 옥션원 이미지형 목록 PDF 여러 개를 드래그해 후보를 일괄 등록합니다.
- 기존의 전체 페이지 OCR 대신 사건번호 / 주소·단지 / 감정가·최저가 / 경매기일 열을 각각 분리·확대해 OCR 정확도를 높였습니다.
- PDF 표의 가로 구분선을 감지해 사건번호와 같은 행의 주소·가격·기일을 결합합니다.
- 사건번호와 금액은 숫자 전용 OCR을 사용합니다.
- 저장 전 미리보기의 사건번호, 주소, 층·호, 평형, 감정가, 최저가, 기일을 직접 수정할 수 있습니다.
- 기존 미검토 / 고민중 / 입찰하기 / 입찰안함 드래그 분류 및 계산기 기능은 그대로 유지합니다.
- AI API는 사용하지 않습니다. OCR은 브라우저에서 Tesseract.js로 처리합니다.

주의: 이미지 OCR 특성상 한글 주소·단지명이 100% 정확할 수는 없습니다. 특히 아주 작은 글씨나 특수 폰트는 일부 수정이 필요할 수 있습니다.
