# v1.14.0 주요 변경

- **v1.13.0을 기준본으로 유지**하면서 화면 구조를 저장목록 중심으로 재구성했습니다.
- 저장목록을 기본 큰 화면으로 보고, 물건을 누르면 왼쪽 목록이 좁아지고 오른쪽 상세분석칸이 열립니다.
- 상세칸 상단에는 층/최고층, 호수, 향, 현관구조, 사용승인년도, 전용면적, 공급평형, 세대수, 방/욕실, 감정가/최저가, 매도확실성, 실거주경쟁, 특이사항이 고정 표시됩니다.
- 상세계산 / 대출 / 비용 / 실제입찰 / 입찰결과 / 메모를 오른쪽 세로 탭으로 전환합니다.
- 예상 빠른 매도가는 **하단 ~ 상단**, 목표 수익률은 기본 **10% ~ 15%**로 입력합니다.
- 목표수익을 만족하는 **입찰가능가격 / 입찰가율 / 예상순수익 / 실제 종잣돈 / 당장 종잣돈 / 시장대비 입찰여유**를 모두 `~` 범위로 표시합니다.
- 저장목록 정렬에 **10% 수익 입찰가율**과 **시장 대비 입찰여유**를 추가했습니다.
- 기존 Firebase 동기화, 대출/DSR, 실제입찰, 피드백 달력, 입찰결과 기능은 유지합니다.

# 경매 입찰·대출 자금 계산기 v1.14.0

## v1.14.0 변경사항

- `물건선정 1차 필터`를 신설했습니다. 동일번지·인근 낙찰가율로 먼저 탈락시키지 않고 `현재 최저매각가 / 보수적 빠른 매도가 / 최소 순수익 / 최소 수익률`을 기준으로 내 최대입찰가를 역산합니다.
- 빠른 매도 확실성, 실거주 입찰 경쟁, 최근 거래 활발도, 권리·명도 위험을 함께 저장해 `A 적극 조사 / B 조건부·저가낙찰 후보 / C 우선 제외`로 분류합니다.
- 동일·인근 대표 낙찰가율이 내 최대입찰가율보다 높아도 물건을 지우지 않고 `저가낙찰 대기` 후보로 유지합니다.
- 최대입찰가 계산은 선택한 대출방식과 기존 대출조건, 취등록세·법무비·명도비·수리비·중개보수·미납관리비·추가지출·중도상환수수료·이자·소득세를 반영합니다.
- `내 최대입찰가율을 계산기에 적용` 버튼을 추가했습니다.
- 저장목록 카드에 물건선정 등급, 내 최대입찰가, 최저가 대비 입찰여유, 저가낙찰 대기 여부를 표시하고 등급/입찰여유 정렬을 추가했습니다.
- 저장한 물건에 `결과입력` 버튼을 추가했습니다. 낙찰/패찰/무효/취하·변경/불참, 내 실제 입찰가, 실제 낙찰가, 입찰자 수, 순위, 메모를 저장할 수 있습니다.
- 입찰결과 저장 시 피드백 달력의 결과 상태도 함께 연동합니다.
- 물건선정 화면의 최저가·빠른 매도가는 실제입찰 화면을 처음 열 때 기본값으로 이어집니다. 기존 실제입찰·대출·Firebase revision 충돌방지 구조는 유지합니다.

## 배포
ZIP을 풀어 GitHub 저장소 루트에 파일을 덮어쓰기 업로드하세요. 제목 옆 `v1.14.0` 표시로 배포 여부를 확인할 수 있습니다.

# 경매 입찰·대출 자금 계산기 v1.12.7

## v1.12.7 변경사항

- 대출별 `3. 계산결과`의 `지금 당장 필요 종잣돈`을 실제입찰 화면과 같은 비용 기준으로 맞췄습니다: `낙찰가 − 대출금 + 법무비(자동추정) + 명도비 + 수리비 + 미납관리비`.
- 계산기에서는 명도비 `250만원`, 수리비 `200만원`을 기본값으로 사용합니다.
- 해당 물건의 실제입찰 자료에서 명도비·수리비를 수정해 저장하면, 같은 물건을 계산기에 열었을 때 대출별 `지금 당장 필요 종잣돈`에도 그 수정값이 자동 반영됩니다. 실제입찰 지정을 해제하면 다시 250만원/200만원 기본값으로 돌아갑니다.
- 미납관리비는 기존 계산기 `미납 관리비` 입력값을 그대로 사용하고, 법무비는 각 입찰가 기준 자동추정값을 사용합니다.
- `총 필요 자기자본` 계산은 기존 경비율·기타 추가지출 구조를 그대로 유지하여 기존 기능과 예산판정에 영향을 주지 않습니다.


## v1.12.6 변경사항

- 실제입찰 수익률표의 `최종 필요 종잣돈` 바로 아래에 `지금 당장 필요 종잣돈`을 추가했습니다. 취등록세(카드납부 전제), 매도 중개수수료, 중도상환수수료, 대출이자는 현금 즉시 필요액에서 제외하고 법무비·명도비·수리비·미납관리비는 포함합니다.
- 대출별 계산결과에도 `지금 당장 필요 종잣돈`을 별도로 표시합니다. 여기서는 낙찰가−대출금 + 법무비 자동추정 + 미납관리비·기타 추가지출로 계산하고, 기존 `총 필요 자기자본`은 경비율을 포함한 보수적 전체자금 기준으로 그대로 유지합니다.
- 하단 비교표에도 세 대출별 즉시 필요 종잣돈을 한 줄로 추가했습니다.

- 실제입찰 1차/2차/3차 입찰가를 수기로 바꾸면 각 제목의 입찰가율 퍼센트도 감정가 기준으로 즉시 갱신.
- 실제입찰의 1차/2차/3차 제목을 누르면 계산기에 저장된 낮음/대표/높음 예상가율 입찰가로 즉시 복원.

## v1.12.1
- 계산내역 저장 단계에서 `고민중`·`입찰하기` 물건에 실제입찰 미리 지정값 프리셋을 선택해 물건별로 저장할 수 있습니다. 실제입찰을 처음 열 때 중도상환수수료율·대출 연이율·이자 계산기간·연간 예상 기존소득이 자동 입력되며, 기존 실제입찰 자료가 있는 물건은 선택한 지정값 4개 항목만 갱신합니다.
- 저장목록의 전체/고민중/입찰 X/입찰 O 상태 필터와 별개로 빈별·검정·노랑·빨강·별 없음 필터를 함께 적용할 수 있습니다.
- 사건번호/아파트명 검색 옆 경매기일 검색은 기존 1일 검색을 유지하고, `기간검색` 버튼으로 시작일~종료일 범위 검색을 전환할 수 있습니다.
- 저장카드에 선택한 실제입찰 지정값 이름을 표시해 어떤 프리셋이 연결되어 있는지 확인할 수 있습니다.

- 오른쪽에는 수기로 입력한 실제 입찰금액의 감정가 대비 `현재 퍼센트`를 별도로 표시합니다.
