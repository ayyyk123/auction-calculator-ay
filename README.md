# 경매 입찰·대출 자금 계산기 v1.21.7

## v1.21.7
- 피드백의 `점유상태`, `누수 확인`을 한 줄 입력칸에서 긴 내용을 적을 수 있는 전체폭 다중행 입력칸으로 변경했습니다.
- 저장목록 정렬 시 현재 보고 있는 물건을 맨 위에 강제로 고정하던 동작 제거. 현재 물건은 행 강조만 유지하며 매각기일 등 선택한 정렬 순서를 그대로 따릅니다.
- 피드백의 자동 제안값은 최초 값이 없을 때만 채웁니다. 가격 선정 이유·미납관리비 등 자동값을 사용자가 지우고 빈칸으로 저장하면 다시 자동 생성되지 않습니다.
- 피드백의 반복 기본값도 사용자가 해당 물건에서 명시적으로 빈칸으로 저장한 경우 그 빈칸을 우선합니다.



## v1.21.7

- 높이조절 손잡이를 저장설정 아래가 아니라 **저장목록 표 바로 아래**로 이동했습니다.
- 저장목록을 항상 화면 최상단 흐름으로 유지하고, 저장설정 영역을 **저장목록 바로 아래 / 아파트 상세 바로 위**의 압축형 한두 줄 바 형태로 이동했습니다.
- 저장 이름·지역폴더·실제입찰 지정값 입력칸 폭을 줄이고, 입찰여부·관심별표·선택사유는 그대로 유지합니다.
- 옥션원 상세 상단의 복잡한 자료완성도 카드/배지 묶음을 제거하고 **자료완성도 퍼센트만** 표시합니다.
- 자료완성도에 포함되는 상세 입력칸 중 비어 있는 칸은 빨간 테두리/연한 빨강 배경으로 바로 보이게 표시합니다.
- 저장목록 표에 **자료완성도** 열을 추가했습니다. 퍼센트를 누르면 해당 행 바로 아래 한 줄이 펼쳐져 채워야 할 항목을 보여줍니다.
- 저장목록 자료조회 도구에 **기존자료 후보 확인** 버튼을 추가했습니다. 체크한 물건만 후보를 확인하고 선택 적용합니다.
- 옥션원 유찰횟수는 사건번호 옆, 매각시간은 날짜 옆, 현재 최저가율은 최저가 옆 괄호로 표시합니다. 평당가·대지권·조회수·공시가격·실거래건수·실거래 중앙값·공공 참고가는 상세 상단에서 제거했습니다.
- 공시가격대·옥션원 조회수·실거래 3/6/12개월 건수·실거래 중앙값·공공 참고가는 `시세입력` 메뉴에서 확인합니다. 공공 참고가는 **최종 예상매도가가 아니라 참고가**라고 명확히 표시되며 사용자가 적용 버튼을 눌러야 예상매도가 후보로 들어갑니다.
- 기존 v1.21.2의 검색/날짜 초기화, 표 필터 초기화, 열 너비 드래그, 피드백 달력 드래그 일정짜기, 공공자료 오류 사건별 확인 기능은 유지합니다.

## v1.21.2
- 저장목록 자료수집은 **원문 재분석 / 공공자료 조회** 두 버튼만 남겼습니다. 둘 다 현재 체크한 물건에만 실행됩니다.
- `필터 초기화`로 검색어, 날짜/기간, 엑셀형 열필터, 정렬을 한 번에 초기화합니다.
- 별도 전체선택/전체해제 버튼은 제거하고, 표 맨 왼쪽 **선택** 제목을 누르면 현재 표시목록 전체선택/전체해제가 토글됩니다.
- 지역폴더와 상태의 추가·이름수정·삭제 기능은 별도 관리 버튼 대신 **각 열의 ▼ 필터 메뉴** 안에서 실행합니다.
- `피드백 일정짜기`는 저장목록에서 제거하고 **피드백 달력 안으로 이동**했습니다. 달력 오른쪽에 고민중·입찰 O 후보목록을 표시하고 마우스로 피드백 마감일에 드래그해 계획합니다.
- 이미 요청되어 진행중인 피드백은 일정짜기 달력에 고정 표시되고, 현재 선택과 겹쳐 동시 진행 3건 이상이 되는 후보는 자동 비활성화됩니다. 선택을 빼면 가능한 후보가 즉시 다시 활성화됩니다.
- 달력 각 영업일의 **“→ 몇 일자 매각기일 건” 피드백 마감 표시**를 그대로 유지합니다.
- 공공자료 조회 후 오류가 있으면 저장목록 위에서 **사건번호별 오류 원인**을 펼쳐 볼 수 있습니다. 이전 버전에서 저장된 `lastErrors`도 복구해 보여주며 실거래 월별 실패 사유도 표시합니다.
- 모바일 하단의 중복 `계산내역 저장 / 새 계산` 바를 제거했습니다. 저장목록에서 상태·별·지역폴더 변경은 즉시 자동저장됩니다.
- 모바일 저장목록은 선택/별/상태/사건번호/아파트/층/최저가/매각기일의 핵심열만 고정 순서로 보여주고, 검색·날짜·자료조회·선택작업 영역을 2줄 단위로 정리했습니다. 상세는 행을 눌러 확인합니다.
- 기존 실거래 건별 조사메모, 호가 건별 입력, 부동산 조사, 15항목 피드백 자동완성, 입찰결과 달력 누적기록, 상세/실제입찰/대출/비용 기능은 유지합니다.

## 공공데이터 사용 순서
1. 저장목록의 `공공데이터 키` → 공공데이터포털 일반 인증키 입력 → `키 저장`.
2. `3개 API 연결 확인`으로 법정동코드 / 건축HUB / 아파트 실거래 응답을 확인합니다.
3. 저장목록에서 조회할 물건 체크 → `공공자료 조회`.
4. 전체 저장목록을 조회하려면 필터를 원하는 범위로 맞춘 뒤 표의 `선택` 제목으로 현재 표시목록 전체선택 → `공공자료 조회`.
5. 오류가 있으면 저장목록 위 `공공자료 조회 오류 확인`을 펼쳐 사건번호별 원인을 확인합니다.

## 이번 버전 핵심
- 저장목록의 `넓게 보기/기본 너비` 버튼을 제거했습니다.
- 상세의 `상세계산/대출/비용/실제입찰/입찰결과/시세입력/피드백요청/메모` 탭을 눌러도 브라우저 화면이 상단으로 이동하지 않도록 현재 스크롤 위치를 유지합니다.
- 저장목록을 엑셀형 표로 사용: 각 열의 ▼ 버튼에서 오름차순/내림차순 정렬, 값 검색, 복수 체크 필터.
- 화면 위쪽의 기존 상태/등급/별/간이필터는 숨기고 표 헤더 필터로 통일.
- 옥션원 원문 재분석, 공공자료 조회, 기존자료 후보 확인 기능 유지.
- 표의 물건을 펼쳐 실제입찰/대출/비용/시세/피드백요청 등 기존 상세 기능 사용.
- 상세영역과 목록 사이 높이는 드래그로 조절하고 마지막 높이를 기억.
- 2~4건 선택 비교 기능 유지.
- `피드백 일정짜기` 모드: 고민중·입찰 O 물건을 목록에서 직접 선택. 동시 진행 최대 2건 규칙에 따라 함께 선택할 수 없는 경매일 물건은 즉시 비활성화되며, 선택을 해제하면 다시 활성화.
- 선택한 일정은 각 경매일의 기본 피드백일(4영업일 전, 주말/공휴일 제외)로 저장 가능. 기존 요청 진행중 물건은 슬롯에 자동 반영.
- `피드백 달력`을 누르면 계산기/저장목록을 숨기고 달력이 화면 최상단에 표시. 경우의 수 계산 기능도 유지.

## 사용 흐름
1. 옥션원 검색결과 복사 → 붙여넣기/저장
2. 원문 재분석 / 공공자료 조회
3. 표 헤더 필터로 1·2층, 대항력, 유찰횟수, 최저가율, 매각기일 등을 정렬·필터
4. 남은 물건부터 시세입력 → 가능입찰가율 확인 → 상태변경
5. 필요하면 2~4건 비교
6. `피드백 일정짜기`에서 경매일 조합을 선택하고 충돌을 확인한 뒤 일정 저장
7. `피드백 달력`에서 요청/결과를 관리

기존 Firebase 동기화와 백업 구조를 유지합니다.

- `피드백 경우의 수`의 포기/후순위 목록에서도 +1영업일 늦추면 가능한 물건을 빨간색으로 표시합니다.
