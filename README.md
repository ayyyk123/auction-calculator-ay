# 경매 입찰·대출 자금 계산기 v1.6

## 주요 변경
- 이메일·비밀번호를 직접 입력하는 로그인으로 변경
- 가계부와 같은 이메일·비밀번호 사용 가능
- 경매계산기 Firebase 프로젝트에서는 처음 한 번 별도 계정 생성 필요
- v1.5에서 짧은 아이디로 만든 계정도 계속 로그인 가능
- PC와 모바일 모두 글씨 크기·카드 여백·입력칸 높이 축소
- 모바일 하단 `최신자료 저장` 버튼 유지
- Firebase 자동동기화 및 revision 충돌방지 유지
- 지역 폴더, 경매기일, 전체목록과 정렬 기능 유지
- 브라우저 탭 favicon 유지

## Firebase에서 꼭 할 일
Authentication > 로그인 방법에서 **이메일/비밀번호** 제공업체를 사용 설정하세요.

## 최초 사용 순서
1. 가계부에서 쓰는 이메일과 비밀번호를 입력합니다.
2. `처음 계정 만들기`를 누릅니다.
3. 이후 PC와 핸드폰에서 같은 이메일·비밀번호로 로그인합니다.

가계부와 경매계산기는 Firebase 프로젝트가 다르므로 로그인 문자열은 같게 쓸 수 있지만, 계정과 저장 데이터는 서로 별도로 관리됩니다.

## 배포
이 폴더 안의 10개 파일을 GitHub 저장소 루트에 모두 업로드하고 기존 파일을 덮어쓰세요.
GitHub Pages는 main / root로 배포합니다.

## 데이터 안전
저장 직전에 Firestore 최신 revision을 확인합니다. 다른 기기에서 먼저 수정한 자료가 있으면 오래된 화면의 저장을 중단하고 최신 클라우드 자료를 불러옵니다.
