# 경매 입찰·대출 자금 계산기 v1.12.5

## 변경사항
- 실제입찰 입력화면의 1차·2차·3차 영역 위에 실제입찰 전용 메모 입력란 추가
- 메모는 해당 물건의 실제입찰 자료에만 저장되며 저장목록/계산기 화면에는 표시하지 않음
- 피드백 달력 추가: 고민중·입찰 O 물건만 달력에 자동 반영
- 경매기일에서 4영업일을 역산한 피드백 기준일 자동 계산(토·일·대한민국 공휴일·대체공휴일 제외)
- 사건번호 클릭 시 피드백 요청 여부·실제 요청일·입찰결과·계획일 입력
- 사건번호 드래그로 피드백 요청 계획일 변경, 기준일은 사건번호 옆에 계속 표시
- 하루 물건이 많으면 +N건 버튼으로 펼쳐보기
- 달력 아래에서 입찰안함 물건 별도 필터·검색
- 피드백 화면에서 해당 사건의 계산기·실제입찰 화면으로 바로 이동
- 기존 Firebase revision 충돌방지와 저장 데이터 구조 유지
- 물건 기본정보에 현관 구조(계단식·복도식·혼합식) 추가
- 기타 특이사항 한 줄 입력란 추가
- 사용승인년도는 저장목록에서 `2016년식`처럼 표시
- 저장 폴더 이름 수정 기능 추가
- 폴더 이름 수정 시 해당 폴더의 기존 저장자료도 함께 새 폴더명으로 안전하게 변경
- 지역별 폴더 보기는 가로 버튼 대신 `폴더 목록` 버튼을 눌러 선택하는 방식으로 변경
- 저장 시 `입찰하기 / 입찰 안 함` 선택과 선택 사유 입력 추가
- 저장카드에 입찰 결정과 사유 표시
- `입찰하기`로 저장한 물건에만 작은 실제입찰 버튼 표시
- 입찰 안 함으로 바꾸면 기존 실제입찰 자료 삭제 여부 확인
- 기존 Firebase 동기화·revision 충돌방지·삭제 tombstone 유지

## v1.11.5

- 계산기와 피드백 달력 목록의 별표가 동일한 `feedback.star` 값으로 양방향 연동
- 달력 아래 목록은 별표 5개가 펼쳐진 형태 대신 단일 별 버튼을 누르면 선택창이 뜨는 방식으로 변경

- 선택 후에는 선택한 별 하나만 목록에 남고, 달력 사건번호 앞에도 동일한 별을 표시


## v1.11.6
- 동일번지·인근 낙찰가율을 이상치 완화, 동일번지 우선, 최근 연도 가중으로 보정해 낮음·대표·높음 3개 예상가율 자동 산출
- 낮음·대표·높음 각각의 최소 자기자본 자동 계산
- 대표 예상가율은 예산 초과지만 낮음 예상가율에서는 가능한 고민중 물건을 저장목록에서 `↘ 낮음 기준 예산OK`로 강조
- 저장목록에 낮음/대표/높음 예상가율을 함께 표시


## v1.11.7
- 저장목록의 `최소자본` 금액이 어떤 입찰가율을 기준으로 계산됐는지 함께 표시
- 낮음 예상가율과 일치하면 `낮음 기준`, 대표 예상가율이면 `대표 기준`, 높음 예상가율이면 `높음 기준` 배지 표시
- 세 시나리오와 다른 수동 입찰가율로 저장한 경우 `직접설정 00.0%`로 표시
- 기존 `↘ 낮음 기준 예산OK` 후보 강조와 낮음/대표/높음 예상범위 표시는 그대로 유지

## v1.11.8
- 저장목록 사건번호/제목 앞에 계산기·피드백 달력과 동일한 관심 별표를 색상까지 그대로 표시
- 저장목록의 최소자본 표시를 `대표 최소 4,350만원 (예산 4,400만원)`처럼 한 줄로 통합
- 낮음/대표/높음 시나리오와 일치하면 각각 `낮음`, `대표`, `높음`을 앞에 표시하고, 수동 입찰가율이면 `직접 00.0%`로 표시
- 기존 `↘ 낮음 기준 예산OK` 강조와 낮음/대표/높음 예상범위는 그대로 유지


## v1.11.9
- 예상가율 산식을 단순화: 동일번지 평균과 인근 평균에 사용자가 정한 반영비중만 적용하고, 연도 가중·개별 이상치 가중·가중 분위수 계산은 제거
- 낮음·높음 예상가율은 전체 입력사례의 퍼짐(표준편차)을 이용해 대표값 아래·위의 현실적인 범위로 계산하며, `낮음 ≤ 대표 ≤ 높음`을 항상 유지
- 낙찰연도는 기존 데이터 호환을 위해 유지하되 계산에는 쓰지 않고 참고용으로만 저장
- 낮음/대표/높음 예상가율 카드를 누르면 `적용할 입찰가율` 조절바가 해당 값으로 즉시 이동하고, 계산결과도 같은 값으로 즉시 재계산
- 선택한 시나리오 카드는 테두리로 강조되며 수동으로 조절바를 움직이면 현재 값과 일치하는 카드만 자동 강조


## v1.12.0
- 물건 기본정보의 층/최고층 입력칸을 넓고 반응형으로 바꿔 창 너비가 좁아도 입력값이 잘 보이도록 개선했습니다.
- 실제입찰 1차/2차/3차는 각각 낮음/대표/높음 예상가율 금액으로 자동 채웁니다. 계산내역을 다시 저장하면 기존 실제입찰 자료가 있어도 세 입찰가격만 최신 시나리오로 갱신됩니다.
- 실제입찰 화면에 여러 개의 이름 지정 가능한 프리셋을 추가했습니다. 중도상환수수료율, 대출 연이율, 이자 계산기간, 연간 예상 기존소득을 세트로 저장하고 `이름 입력` 버튼 한 번으로 적용할 수 있습니다.
- 지정값 프리셋은 사용자 설정으로 Firebase에 동기화됩니다.




## v1.12.4

- v1.12.2를 기준으로 기능은 그대로 유지했습니다.
- 모바일에서 `계산내역 저장 / 새 계산` 바의 하단 고정만 해제했습니다.
- 버튼 바는 페이지 내용과 함께 자연스럽게 스크롤되며, 고정 바 때문에 필요했던 큰 하단 여백도 제거했습니다.
- v1.12.2의 모바일 제목영역 접기/펴기, 별색상 복수선택 필터, 실제입찰 수기 입찰가율 자동표시 및 1·2·3차 시나리오 복원 기능을 그대로 유지합니다.

## v1.12.2
- 모바일 계산기 메뉴는 별도 접기/펴기 버튼 대신 메뉴명 왼쪽 상단 영역 전체를 눌러 접기/펴기 가능하도록 개선. 모바일에서는 접기/펴기 버튼을 숨겨 위/아래 이동 버튼 오조작을 줄임.
- 저장목록 관심 별표 필터를 복수 선택 방식으로 변경. 입찰상태 복수필터와 함께 여러 별 색을 OR 조건으로 동시에 검색 가능.
- 실제입찰 1차/2차/3차 입찰가를 수기로 바꾸면 각 제목의 입찰가율 퍼센트도 감정가 기준으로 즉시 갱신.
- 실제입찰의 1차/2차/3차 제목을 누르면 계산기에 저장된 낮음/대표/높음 예상가율 입찰가로 즉시 복원.

## v1.12.1
- 계산내역 저장 단계에서 `고민중`·`입찰하기` 물건에 실제입찰 미리 지정값 프리셋을 선택해 물건별로 저장할 수 있습니다. 실제입찰을 처음 열 때 중도상환수수료율·대출 연이율·이자 계산기간·연간 예상 기존소득이 자동 입력되며, 기존 실제입찰 자료가 있는 물건은 선택한 지정값 4개 항목만 갱신합니다.
- 저장목록의 전체/고민중/입찰 X/입찰 O 상태 필터와 별개로 빈별·검정·노랑·빨강·별 없음 필터를 함께 적용할 수 있습니다.
- 사건번호/아파트명 검색 옆 경매기일 검색은 기존 1일 검색을 유지하고, `기간검색` 버튼으로 시작일~종료일 범위 검색을 전환할 수 있습니다.
- 저장카드에 선택한 실제입찰 지정값 이름을 표시해 어떤 프리셋이 연결되어 있는지 확인할 수 있습니다.

## v1.12.4
- 실제입찰 1·2·3차 상단에 계산기에서 저장된 `낮음 / 대표 / 높음` 원래 퍼센트를 왼쪽에 고정 표시합니다.
- 오른쪽에는 수기로 입력한 실제 입찰금액의 감정가 대비 `현재 퍼센트`를 별도로 표시합니다.
- 왼쪽 `1차 · 낮음 xx.x% / 2차 · 대표 xx.x% / 3차 · 높음 xx.x%`를 누르면 해당 계산기 시나리오 금액으로 즉시 복원됩니다.
- v1.12.3의 모바일 하단 고정 해제, 별색상 복수필터, 모바일 제목영역 접기/펴기 등 기존 기능은 그대로 유지합니다.
