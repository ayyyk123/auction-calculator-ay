## v1.18.0

- 옥션원 붙여넣기 원문 재분석을 `기존자료 자동보완`과 완전히 분리했습니다.
- 선택한 미검토 / 미검토 전체를 목록에서 한 번에 `옥션원 원문 재분석`할 수 있습니다.
- 기존 계산기 자료는 자동 적용하지 않습니다. 같은 법정동의 같은 아파트를 기준으로 동·전용면적·호수라인 후보를 먼저 표로 보여주고 현재값/후보값/출처를 확인한 뒤 체크한 항목만 적용합니다.
- 공공데이터포털 서비스키를 이 브라우저에만 저장하는 설정창을 추가했습니다. 키는 Firebase와 백업에 저장하지 않습니다.
- 행정안전부 법정동코드 API를 이용해 지번주소에서 법정동코드를 찾습니다.
- 국토교통부 건축HUB 건축물대장정보에서 도로명주소·사용승인년도·최고층·세대수를 빈칸에 자동 입력합니다.
- 국토교통부 아파트 매매 실거래가 상세 API에서 동일 아파트·동일 전용면적 최근 12개월 거래를 조회하고 3/6/12개월 거래건수·중앙값·하단값·최근거래를 저장합니다. 거래활발도는 거래건수로 자동 분류합니다. 실거래의 건축년도는 사용승인년도로 간주하지 않아 해당 칸을 덮어쓰지 않습니다.
- 실거래만으로 빠른매도가를 임의 확정하지 않고, 보수적 참고범위만 상세 상단 배지로 보여줍니다.
- 목록 상단에서 선택 공공자료 조회 / 미검토 전체 공공자료 조회가 가능합니다. 같은 법정동·월 실거래 응답은 실행 중 재사용해 API 호출을 줄입니다.
- 자료완성도 그룹의 출처 설명을 `옥션원 원문 / 공공데이터 / 기존자료 확인후 / 직접확인`으로 정리했습니다.
- 앱/캐시 버전 v1.18.0, schemaVersion 17.

### 공공데이터 활용신청
공공데이터포털에서 아래 3개 API를 활용신청한 뒤 일반 인증키를 앱의 `공공데이터 키 설정`에 한 번 입력합니다.
1. 행정안전부_행정표준코드_법정동코드
2. 국토교통부_건축HUB_건축물대장정보 서비스
3. 국토교통부_아파트 매매 실거래가 상세 자료

외부 API의 응답/CORS/활용승인 상태에 따라 특정 출처가 실패할 수 있으며, 실패한 출처는 기존 값을 덮어쓰지 않습니다.
