# 경매 입찰·대출 자금 계산기 v1.5

## 주요 변경
- Google 팝업 대신 아이디·비밀번호 로그인
- Firebase 이메일/비밀번호 인증 기반 PC·핸드폰 자동동기화
- 기존 revision 거래 방식 유지: 오래된 기기가 최신 저장자료를 덮어쓰지 못하도록 차단
- `최신자료 저장` 버튼과 모바일 하단 고정 저장버튼
- 지역 폴더와 경매기일 입력
- 지역별 폴더 보기 및 전체목록 보기
- 경매기일, 최소/가계/신탁/사업자근저당 필요 자기자본, 저장일 정렬
- 정렬 ↑/↓ 전환
- 모바일 여백·입력칸·카드 간격 축소
- 번호 블록 접기/펼치기 및 전체 접기/펴기
- 브라우저 탭 favicon 추가

## Firebase에서 꼭 할 일
Authentication > 로그인 방법에서 **이메일/비밀번호** 제공업체를 사용 설정하세요.
Google 제공업체는 켜져 있어도 상관없지만 이 버전에서는 사용하지 않습니다.

## 배포
이 폴더 안 파일을 GitHub 저장소 루트에 모두 업로드하고 GitHub Pages를 main / root로 배포하세요.
기존 v1.4 파일 위에 전부 덮어써야 서비스워커와 아이콘도 갱신됩니다.

## 데이터 안전
저장 직전에 Firestore 최신 revision을 확인합니다. 다른 기기에서 먼저 수정된 경우 저장을 중단하고 클라우드 최신자료를 불러옵니다.
