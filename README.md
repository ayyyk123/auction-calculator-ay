# 경매 입찰·대출 자금 계산기 v1.7

## 변경사항
- 저장목록의 버튼을 `계산내역 저장`으로 수정
- 상단 `백업·인쇄 도구` 옆에 `최신자료 저장` 버튼 추가
- `최신자료 저장`은 저장목록 전체와 지역 폴더를 Firebase 최신 상태로 확인·동기화하며 새 계산내역을 만들지 않음
- 계산내역 저장 전에 저장할 지역 폴더를 선택하도록 변경
- `폴더 만들기` 버튼으로 사용자 지정 지역 폴더 생성
- 지역별 폴더 화면에 빈 폴더도 표시
- 물건의 실제 지역과 저장 폴더를 분리
- 기존 v1.6 이하 자료는 기존 지역값을 폴더로도 인식하여 호환
- 경매기일·자기자본 정렬, 모바일 압축 화면, 이메일 로그인, favicon 유지
